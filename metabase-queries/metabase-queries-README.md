# Metabase Dashboard Queries

This folder contains SQL queries for recreating TaskFlow dashboards in Metabase.

## Setup Instructions

1. Open Metabase: http://localhost:3000
2. Create account (if needed)
3. Add TaskFlow Analytics database connection (see main README)
4. Create dashboards using queries below

---

## How to Use These Queries

For each query file:
1. In Metabase, click "+ New" → "Question"
2. Select "Native query" (SQL)
3. Select "TaskFlow Analytics" database
4. Copy/paste the SQL
5. Click "Visualize"
6. Choose the visualization type noted in the file header
7. Save to the appropriate dashboard
